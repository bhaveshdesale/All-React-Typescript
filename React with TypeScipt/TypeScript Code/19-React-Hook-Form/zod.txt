Interview Questions From Today's Session
1. Is Zod a React library?

❌ No.

It's a TypeScript-first runtime validation library.

2. Does Zod replace TypeScript?

❌ No.

TypeScript checks types at compile time.

Zod checks values at runtime.

3. Why use Zod with React Hook Form?

Because React Hook Form manages the form, while Zod centralizes and validates the form's data in reusable schemas.




Interview Questions - 
Difference between .min() and .max()
.min() → minimum length/value
.max() → maximum length/value

Difference between .email() and .regex()
.email() → built-in email validation
.regex() → custom pattern validation

Difference between .optional() and .nullable()
.optional() → field may be omitted.
.nullable() → field exists but can be null.

import { z } from "zod";

export const signupSchema = z.object({

  fullName: z
    .string()
    .min(3, "Minimum 3 characters")
    .max(50, "Maximum 50 characters"),

  email: z
    .string()
    .email("Invalid Email"),

  password: z
    .string()
    .min(8, "Minimum 8 characters"),

  age: z
    .number()
    .min(18, "Must be 18+"),

  phone: z
    .string()
    .regex(
      /^[0-9]{10}$/,
      "Phone must be 10 digits"
    ),

  website: z
    .string()
    .url("Invalid URL")
    .optional(),

});
