Project: Blog CRUD Dashboard
What We'll Build

A dashboard where users can:

- View all blogs
- Create a new blog
- Update a blog
- Delete a blog
- Automatically refresh the UI after every mutation
- Use RTK Query caching
- Use cache invalidation
- Follow production folder structure
- Use reusable components
= Use TypeScript everywhere
