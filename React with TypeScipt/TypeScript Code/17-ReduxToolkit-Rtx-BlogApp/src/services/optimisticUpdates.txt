Optimistic Update
Optimistic Update is a technique where the UI is updated immediately before the server confirms the operation. If the request fails, the UI is rolled back to its previous state.

What is onQueryStarted?

A lifecycle callback that executes immediately when a query or mutation starts, before the server response is received.

What is updateQueryData()?

A utility that allows direct modification of cached query data.

What is queryFulfilled?

A promise that resolves when the API request succeeds or rejects if it fails.

Why is patchResult.undo() needed?

It rolls back the optimistic cache update if the server request fails, keeping the UI consistent with the backend.
