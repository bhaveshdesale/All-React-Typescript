Definition (Interview)

Prefetching loads data before the user actually needs it, reducing waiting time.


Code

Get prefetch hook

import { usePrefetch }

from "../services/blogApi";

Actually RTK Query provides it through the API object:

const prefetchBlog =
blogApi.usePrefetch("getBlogById");

Suppose

const prefetchBlog =
blogApi.usePrefetch(
"getBlogById"
);

{blog.title}

That's it.



Polling vs Prefetch

| Polling             | Prefetch                 |
| ------------------- | ------------------------ |
| Time based          | User action based        |
| Re-fetch repeatedly | Fetch once before needed |
| Live data           | Better UX                |
