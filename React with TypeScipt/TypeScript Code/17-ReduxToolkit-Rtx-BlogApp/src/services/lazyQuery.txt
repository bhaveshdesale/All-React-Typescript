What is Lazy Query?

A Lazy Query is a query that executes only when its trigger function is called instead of automatically when the component mounts.


Difference Between Mutation and Lazy Query?

This is a very common interview question.

| Lazy Query               | Mutation                   |
| ------------------------ | -------------------------- |
| Uses GET                 | Uses POST/PUT/PATCH/DELETE |
| Reads Data               | Changes Data               |
| Returns Trigger Function | Returns Trigger Function   |
| No automatic execution   | No automatic execution     |
